# 🌏 해외공식 — 해외 대회 공식 포스터

여기에 포스터 이미지(jpg·png·webp)를 올리면 10분 안에 뚝섬 홈 '공식포스터 (해외)' 메뉴에 나와요.

- 파일명 규칙은 국내 공식 폴더와 같아요
  - 앞에 6자리 날짜: `261120_APT 타이베이.jpg` → 11/20 다음 날부터 자동 숨김
  - 기간: `261101-261130_WSOP 서킷.jpg` → 끝나는 날 다음 날부터 자동 숨김
  - 끝에 `_PC` / `_MOBILE` 을 붙이면 기기별 이미지
- 대회사별로 나누고 싶으면 저장소 맨 위에 `해외공식WSOP`, `해외공식APT` 처럼 폴더를 새로 만들면 버튼이 자동으로 생겨요
- 이 폴더 포스터는 보기 전용이에요 (OCR·국내 캘린더에 안 들어감). 일정은 관리자 🏠 홈 관리 → 🌏 해외대회일정에서 입력하세요
